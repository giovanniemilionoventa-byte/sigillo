# AGENTS.md

Start here if you are an AI assistant analysing or working on this repository.

1. Read [`docs/SIGILLO-COMPLETO.md`](docs/SIGILLO-COMPLETO.md): the complete overview of Sigillo (what it is, architecture, receipt format, what it records and does not, privacy, security, legal and business context, open items). It is in Italian; every important claim is labelled `[CODICE]` (verified in code), `[DOCUMENTI]` (from documents) or `[NON VERIFICATO]` (unverified). The code wins if they disagree.
2. Read [`CLAUDE.md`](CLAUDE.md) for the permanent working rules, approved dependencies and build/test commands.
3. Then `docs/FORMAT.md`, `docs/SECURITY.md`, `docs/API.md`; search `PROGRESS.md` (large) rather than reading it whole.

Wording rule: say "tamper-evident" / "independently verifiable", never "tamper-proof", "compliant", "AI Act ready" or "certified".
